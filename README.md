# LafiyaConnect-UX-CaseStudy-
Project Overview
LafiyaConnect is a mobile healthcare application concept specialized in the hematology unit. It is designed to simplify critical diagnostic blood work—such as Full Blood Counts (FBC), Packed Cell Volume (PCV), and genotype screenings—while addressing language barriers through a real-time multilingual interface (English, Nigerian Pidgin, and Hausa).
🎯 Target Users & Problem Statement
 The Problem: Patients and family caregivers often face anxiety, long hospital queues, complex medical terminology, and language barriers when trying to book critical hematology tests and track lab results.
 Target Users:
 Antenatal care patients requiring regular blood profile checks.
 Chronic care coordinators / Family members managing health records for relatives.
🛠️ Design Approach & Tools
 Tools Used: Figma (for wireframing, UI component management, and interactive prototyping).  
 Core UX Methods: Human-centered healthcare design, information architecture, user journey mapping, and multilingual accessibility.  
🗺️ Key User Flows & Wireframes
1 Welcome & Language Selection: Instant toggling between English, Pidgin, and Hausa (⁠EN⁠, ⁠PI⁠, ⁠HA⁠).
2 Main Dashboard (Bento Layout): Quick-action shortcuts for booking tests, viewing results, and reading clinical health tips.
3 Test Selection & Booking Flow: 3-step progress indicator (⁠Details⁠ -> ⁠Date & Time⁠ -> ⁠Confirm⁠) for selecting specific hematology panels.
4 Calendar & Scheduling: Interactive monthly calendar grid with clear time-slot selection pills.
5 Appointment Summary: Review screen verifying test details, lab location, and date before final confirmation.

##Week 2: User Research & Prototyping
- User Research Summary
  Target Audience: Antenatal patients and caregivers managing family health records.
  Pain Points: Language and medical terminology barriers, long physical queues at laboratories, and fragmented record tracking.
  Core Solutions: Real-time language switcher and a streamlined 3-step booking flow.
### Information Architecture & User Journey
  Onboarding: Splash Screen -> Language Selector (EN / PI / HA) -> Authentication.
  Bento Dashboard: Quick booking shortcuts, active appointments tracker, and recent lab results repository.
  Booking Flow: Select Test -> Choose Lab -> Pick Date/Time Slot -> Confirmation.
### Usability Testing & Iterations
  Tested with representative users to evaluate multilingual comprehension and booking speed.
  Feedback led to enhanced contrast on step-indicators and simplified medical jargon on result summary cards.
